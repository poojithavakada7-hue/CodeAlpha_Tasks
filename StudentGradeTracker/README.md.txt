# Student Grade Tracker

## 📌 Project Description
Student Grade Tracker is a Java Swing GUI application developed as part of the CodeAlpha Java Programming Internship.

The application allows users to add student names and marks, then generates a report showing the average, highest, and lowest marks.

## ✨ Features
- GUI-based interface using Java Swing
- Add student names and marks
- Display all student records
- Calculate average marks
- Display highest marks
- Display lowest marks
- Input validation

## 🛠 Technologies Used
- Java
- Java Swing
- ArrayList
- Object-Oriented Programming (OOP)

## ▶️ How to Run

Compile:

```bash
javac Student.java
```

Run:

```bash
java Student
```
