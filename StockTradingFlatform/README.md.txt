# 📈 Stock Trading Platform

## 📌 About the Project

This is a Java-based Stock Trading Platform developed as part of my CodeAlpha Java Programming Internship.

The application simulates stock trading using virtual money. Users can view stocks, buy and sell shares, manage their portfolio, and view their transaction history.

## ✨ Features

- View available stocks and prices
- Buy stocks
- Sell stocks
- View portfolio
- Calculate profit and loss
- View transaction history
- View account balance
- Virtual money for trading

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## 🖥️ How the Application Works

1. Enter your name.
2. View available stocks.
3. Select a stock to buy.
4. Enter the quantity.
5. The purchase amount is deducted from the balance.
6. View your portfolio.
7. Sell stocks when required.
8. View transaction history and profit/loss.
